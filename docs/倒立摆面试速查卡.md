# 倒立摆面试速查卡（直驱摆版 · 面试前 10 分钟过一遍）

## 一句话讲清项目
"12V 减速电机的轴经联轴器、法兰**直接驱动摆杆**，基座固定，**没有小车也没有轨道**。
AS5600 测绝对角度，STM32 每 2ms 闭环一次。
实物打通了 驱动+采集+2ms采样+角度链+数据记录（S1~S2 实机验收）；
平衡控制/起摆/安全在与实物同结构的 2 状态仿真平台上验证（S1~S9）。"

## ⚠️ 最容易讲错的地方
**我的实物是直驱摆：只有 2 个状态（摆角 θ、角速度 ω），控制量是电机力矩。**
如果面试官问"小车位置怎么控"，正确回答是："我的实物没有小车，基座固定。"

## 三个本质
1. **手掌立棍**：看它往哪倒就往哪推 → 负反馈闭环
2. **两条链**：数字→力（PWM→TB6612→电机）；角度→数（磁铁→AS5600→I2C→deg）
3. **仿真**：实物闭环（S3）还没跑通，算法先在仿真验证（诚实口径）

## ⭐ 核心矛盾：摩擦死区（本项目最值钱的一段）
- 摆杆重力矩 ≈ **11.8 mN·m**；减速箱静摩擦 ≈ **5 mN·m**（占 40%+）
- **纯 PD**：从 10° 起步只收到 **6.55°** 就卡住（力矩压不过静摩擦，settle=∞）
- **2 状态 LQR**：一样卡在 **6.51°**（结构等价于 PD，也没有积分）
- **PID（加积分）**：**2° → 1.196s 收敛到 −0.514°**（这才是定点残差）；**10° → 0.518s 进 ±3° 带**，之后是 **±2° 量级极限环**（t≥3s：−2.044°~+2.296°、峰峰 4.34°）——摩擦死区，PID 也收不到严格 0
- 一句话："**PD/LQR 缺积分这一环，跨不过摩擦门槛；积分累积到够大就把杆推回去。**"

## 保命数字（只背这些）
- **2ms**（500Hz，实测 2000±2µs 零漏拍）/ **20kHz** PWM / ARR=3599
- **AS5600 12bit**（0.088°/count，|B|≈1000，绝对角度）
- **11.8 mN·m 重力矩 vs 5 mN·m 静摩擦**
- **kp=60 / kd=8 / ki=100**
- **0.518s**（10° 进 ±3° 带）/ **17.98s**（起摆稳定，末值 −0.048°、末 1s 均值 −0.019°）
- **38 / 58 / 20 ms**（传感器断连 / 占空比饱和 / 看门狗急停）
- **≤30ms 稳定**（采样裕量约 15 倍）

## 三个必讲故事（全是真的）
1. **ARR 坑**：写死 3599 vs CubeMX 65535 → 40% 只出 2.2% → 电机只哼哼 → 按 htim3.Init.Period 实时算
2. **循环量处理（诚实版）**：循环量不能直接滤波/差分（回绕造假差值 −4080）→ 先展开再处理；**实测改完仍有零星 ±1500 尖刺，靠限幅兜底，没造成功能问题**
3. **摩擦死区（新，最重要）**：纯 PD/LQR 卡在死区（6.55°/2.03°）→ 加积分跨过门槛（2° 起步 1.20s 收到 −0.51°；10° 起步受摩擦限制只到 ±2° 极限环）

## 高频问题（简答）
1. 为什么能站住？→ 负反馈闭环，2ms 一修
2. 实物几种状态？→ **2 个（θ、ω），没有小车**
3. 为什么用 PID 不用纯 PD？→ 摩擦死区；PD 停在 6.55°（settle=∞），PID 2° 起步 1.20s 收到 −0.51°；10° 起步受摩擦限制也只到 ±2° 极限环
4. LQR 呢？→ 2 状态 LQR = 系统设计出的一组 PD，结构等价，也没积分 → 一样卡死区
5. 起摆？→ 能量控制，dE/dt = τ·ω，力矩与 ω 同相 → 17.98s 站住（末值 −0.048°）
6. 安全？→ 监测执行分离；断连 38ms / 饱和 58ms / 看门狗 20ms；超角先降级回起摆、不直接停机
7. 降级后救得回来吗？→ **救得回来，而且这段最值得讲**：第一版判据用**连展角**和 ±45° 比，转两圈后角度累积到 1000°+，判据永远不成立 → 日志里看不到重捕获；改成**折回角** + 捕获窗口 10° 滞回后，**0.29s 完成重捕获**。结论：不是算法救不回来，是角度表示搞错了（旧稿"41.4°/2.998s"跑不出来，已弃用）
8. 2ms 怎么保证？→ TIM2 硬件计数 1MHz + 累加推进 + 开机自检
9. AS5600 为什么不用 IMU？→ 绝对角度、无累计误差、直驱同轴最简

## ⭐ 两层模型（容易混）
| 层 | 作用 | 本项目是谁 |
|---|---|---|
| 决策层（大脑） | 每 2ms 算"该出多大力/占空比" | PID（对照：PD、LQR） |
| 执行层（手） | 把"力"变成电机平均电压 | PWM（TIM3 20kHz） |

类比：**"根据水温调水龙头"=算法；水龙头开度=PWM。**
