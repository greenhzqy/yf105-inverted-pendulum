# 接线表 · S1（本轮：只接"电机这一路"）

## 一、电源与动力（先接、先量、再接负载）
| 从 | 到 | 说明 |
|---|---|---|
| 适配器 12V+ | 保险丝座 → 按钮 → TB6612 **VM** | 保险丝 3A、按钮串正极；按钮是"按下断开"的自锁/急停才合格 |
| 适配器 12V− | TB6612 **GND** | 动力地 |
| TB6612 **A01 / A02** | 电机两根线 | 正反随意，反了换线或代码换向 |

## 二、逻辑与信号
| STM32 蓝丸 | TB6612 | 说明 |
|---|---|---|
| **PB0** | PWMA | TIM3_CH3，20kHz |
| **PA0** | AIN1 | 方向 |
| **PA1** | AIN2 | 方向 |
| **PA2** | STBY | 上电默认低=禁能；程序里才放行 |
| **3V3** | VCC | 3.3V 逻辑电源（**千万别接 12V**） |
| **GND** | GND | 与 12V 负极共地（必接，否则信号乱飞） |

## 五、通电前检查（照做）
1. 万用表通断档：**12V 正负极之间不短路**（先别接模块，量线）。
2. 万用表直流档：适配器内芯是 **+**；量出 12V。
3. 接好后再量一次 **TB6612 的 VM-GND = 12V**，且 **VCC-GND = 3.3V**（不是 12V！）。
4. **第一次通电不装摆杆**，电机空转；有异响/发烫/冒烟 → 立刻按急停或拔电。
