# PLAN · 电机直驱倒立摆
> 产品/剧本/架构/决策及依据/怎么跑。变一次落一次；翻案条目带旧方案+为什么翻（本节）。

## 产品是什么
一台 12V 减速电机 + 摆杆（直驱）：磁编码器测摆角，STM32 以 500Hz 闭环，实现"从下垂自动起摆 → 捕获 → 直立保持"；含安全保护（超角/电流/断线/看门狗 → 断电锁存）。

## 剧本
1. 通电摆杆下垂 → 串口角度曲线干净、方向正确；
2. 按开始 → 自动越荡越高 → 被抓住 → 站住；
3. 站住时轻弹（约10°）→ 自动回正；
4. 拔角度线 / 抓杆硬扳 / 程序卡死 → 电机断电。

## 架构 / 形状（已拍：路线 A 直驱摆；末决项见「决策记录」）
- 机械：减速电机（轴=摆杆转轴，支架固定）；摆杆经联轴/顶丝固定在输出轴；磁铁粘轴端，AS5600 贴支架对磁铁（I2C 读 360° 绝对角）。
- 电气：12V 电源（保险丝+开关）→ TB6612 驱动 → 电机；STM32 5V/USB 供电（与电机地共地）；AS5600 挂同 I2C 总线。
- 软件分层：main 循环 2ms 定周期 → 读角（I2C）→ 滤波/估计 → 控制律（S3 起 PD→LQR）→ 输出 PWM+方向；安全监测逐拍运行；串口日志（文本，S2 起可画曲线）。
- 固件目录：`firmware/`（用户工程形式：CubeMX 配置清单 + main.c + module_*.c/h）。

## 怎么跑（构建/部署级）
- 本机（DSH）无 STM32 工具链 → 源码在此维护，**编译/下载在用户自己的 Keil 或 STM32CubeIDE**；
- 本仓库提供：`firmware/CubeMX_配置清单.md`（用户按表在 CubeMX 点选生成工程）+ 模块源码；用户编译后 ST-Link 下载（SWDIO/SWCLK/GND）或串口 ISP；
- 串口：USART1 115200 8N1（调试日志）；AS5600 走 I2C1（F103 PB6/PB7 或按用户板面，见配置清单）。
- 验证工具：串口助手文本曲线；S2 起备曲线工具（确定后再写）。
